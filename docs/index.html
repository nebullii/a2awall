A2AWall

A2AWall is an A2A-compatible security layer for agent discovery, admission, runtime policy, memory, retrieval, delegation, and output validation.

Overview Getting Started Security Model User Guide GitHub

Overview

A2AWall keeps baseline A2A discovery and transport intact while adding security controls around request admission and runtime behavior.

  • Agent Card, JSON-RPC, and REST support for standard A2A clients
  • Admission control for identity, capability, scopes, trust tier, approvals, and size limits
  • Trusted context boundaries for system, user, retrieval, memory, tool, and peer-agent input
  • Sandbox and runtime policy evaluation for tools and actions
  • Memory, retrieval, delegation, and output validation foundations
