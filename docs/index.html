A2A-compatible security gateway

Standard A2A discovery and transport, with stricter gateway controls.

Use A2AWall when you want clients to recognize your agent through the standard protocol, but you need stronger policy enforcement around admission, trust, tools, memory, retrieval, delegation, and output validation.

Positioning

This is not a new protocol.

A2AWall keeps baseline A2A interoperability and adds a security gateway around it. Generic A2A clients can still discover and call the agent. More advanced clients can also read the additional security metadata and behave more intelligently.
