User Guide

Use A2AWall as a starter and security layer

A2AWall preserves standard A2A discovery and transport while layering security controls around the agent runtime.

Overview Getting Started Security Model User Guide GitHub

What is implemented

  • Bearer-token authentication
  • Capability-level authorization
  • Scope and trust-tier checks
  • Approval-gate support
  • Trusted context boundary helpers
  • Tool sandbox policy evaluators
  • Memory and retrieval security foundations
  • Delegation and output validation foundations

Quick start

npm install
cp .env.example .env
npm test
npm run build
npm start
